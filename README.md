#fitbuddy# FitBuddy - AI Fitness Plan Generator

## About
FitBuddy is an AI-powered fitness plan generator that creates personalized workout and diet plans based on age, weight, height and fitness goals.

Team ID: 1669FitBuddy - IGTM Hackathon 2026

## Features
- Personalized workout plan
- Diet plan based on BMI
- Goal: Weight Loss / Muscle Gain / Maintenance
